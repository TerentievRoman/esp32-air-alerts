# Nokia 5110 LCD Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Екран PCD8544 84×48 показує українською час, стан, SSID, MQTT і останній запис журналу.

**Architecture:** Чиста частина (UTF-8, шрифт, формування 6 рядків) у `font5x8.c` і `screen_fmt.c`, тестується на хості. `lcd.c` — драйвер PCD8544 по SPI2. `screen.c` — задача, раз на секунду збирає `screen_info_t` і малює.

**Tech Stack:** ESP-IDF v6.1.1, `driver/spi_master.h`, Python 3 + PIL для генерації шрифту.

**Spec:** `docs/superpowers/specs/2026-11-22-lcd-nokia5110-design.md`

## Global Constraints

- Гліфи з `/usr/share/fonts/X11/misc/5x8.pcf.gz`, читання через `PIL.PcfFontFile(..., charset_encoding='cp1251')`; набір: ASCII 0x20–0x7E + усі символи cp1251 0xA8–0xFF, 0x92 (’), 0x97 (—), 0xB0 (°), 0xA5/0xB4 (Ґґ), 0xAA/0xBA (Єє), 0xB2/0xB3 (Іі), 0xAF/0xBF (Її).
- Клітинка 6×8: 14 символів × 6 рядків; гліф 5 стовпців, 6-й порожній.
- Піни лише з Kconfig: `AA_LCD_RST_GPIO` 4, `AA_LCD_CE_GPIO` 10, `AA_LCD_DC_GPIO` 5, `AA_LCD_DIN_GPIO` 7, `AA_LCD_CLK_GPIO` 6, `AA_LCD_CONTRAST` 0x3F (range 0 0x7F), `AA_LCD_ENABLE` bool y.
- Екран не блокує інші задачі: задача `screen` пріоритет 3, стек 3072.
- Без нових warning-ів у `main/`; хост-тести `make -C tests/host test`.

## Review Focus

1. SSID довший за 14 символів або з кирилицею/емодзі: обрізка по межі символу UTF-8, без «половинок» (тест у Task 2).
2. Символ, якого немає у шрифті (емодзі, ё, ъ): малюється `?`, без краху (тест у Task 1).
3. Час не синхронізовано: `--:--`, запис журналу з `ts == 0`: «час невідомий» (тести у Task 2).
4. Екран не під'єднано або SPI не ініціалізувався: прошивка працює далі, лог ERROR (перевірка Task 3).
5. Порожній журнал і режим AP: осмислені рядки, не сміття (тести у Task 2).

**Interfaces:**
- Produces:
  - `uint32_t utf8_next(const char **s);` — повертає код символу і зсуває `*s`; на `\0` повертає 0 і не зсуває; некоректна послідовність → `0xFFFD`, зсув на 1 байт.
  - `const uint8_t *font5x8_glyph(uint32_t cp);` — 5 байтів-стовпців, біт 0 = верхній піксель; невідомий код → гліф `?`.

### Task 2: формування рядків екрана

**Files:**
- Create: `main/screen_fmt.c`, `main/screen_fmt.h`
- Test: `tests/host/test_screen_fmt.c`

**Interfaces:**
- Consumes: `alert_state_t`, `alert_log_entry_t` (`alert_log_buf.h`), `utf8_next`.
- Produces:
  - `#define SCREEN_ROWS 6`, `#define SCREEN_COLS 14`, `#define SCREEN_LINE_BYTES 64`
  - `typedef struct { bool ap_mode; char ap_ssid[33]; int64_t now; alert_state_t state; bool wifi; char ssid[33]; bool mqtt; bool has_log; alert_log_entry_t last; } screen_info_t;`
  - `typedef struct { char text[SCREEN_ROWS][SCREEN_LINE_BYTES]; bool invert[SCREEN_ROWS]; } screen_lines_t;`
  - `void screen_format(const screen_info_t *in, screen_lines_t *out);` — локальний час через `localtime_r` (TZ встановлено ззовні).
  - `void utf8_truncate(char *s, int max_chars);` — обрізає по межі символу.

Рядки (звичайний режим): 0 `HH:MM   DD.MM` або `--:--`; 1 стан по центру — `ТРИВОГА`/`ДРОНИ`/`ВІДБІЙ`/`НЕВІДОМО`, `invert[1]` для RED і YELLOW; 2 `WiFi <ssid>` (обрізано до 14) або `WiFi немає`; 3 `MQTT ок` / `MQTT немає`; 4 `Ост: Тривога`/`Ост: Дрони`/`Ост: Відбій` або `Журнал`; 5 `DD.MM HH:MM бр|кн`, `час невідомий` при `ts == 0`, або `порожній`.
Режим AP: 0 `Налаштування`, 1 `Мережа:`, 2–3 `ap_ssid` по 14 символів, 4 `Відкрийте`, 5 `192.168.4.1`.

- [ ] **Step 1: Тести** (у `main()` тесту `setenv("TZ","EET-2EEST,M3.5.0/3,M10.5.0/4",1); tzset();`; `T0 = 1795299720` = 2026-11-22 00:22:00 Kyiv):
